# 三平台详情与研究链路优化（2026-10-12）

继续现有 Issue #3 / Draft PR #2，main 不合并。本轮不请求仍受限的淘宝。

## 改动

- 拼多多：接入实站 `.iUUH2sOQ` 标签/值参数容器。视觉可见性依据 CSS 和布局判断，`aria-hidden` 不再被当作视觉隐藏；保留真正隐藏及透明内容检查。品牌和型号来自参数，不来自标题。
- 京东：读取 `.comment-root .list > .item > .info` 的实际评价正文，排除好评标签、累计人数及昵称。“没破损”这类否定表达不算破损风险。评价样本仍可能有偏，不核实真实购买，不生成质量分。
- 闲鱼：读取主商品描述和卖家显示名；“猜你喜欢”的品牌、成色标签不作为主商品参数。卖家自述保留为未核实声明，不用“全新”宣传直接填充成色。
- 参数排序：一次研究先对每个平台的符合目标及预算的候选读取详情，再分组和排序；默认每平台 1 条，可设为 0–2 条。之后读取短名单详情时复用本次缓存，避免重复导航。
- 参数归属：详情商品 URL 必须与候选一致，受限或错商品的内容不会填进身份字段。标题含目标型号但详情显示不同型号时，按详情排除并保留证据。
- 渲染等待：导航后短暂等待详情 DOM，期间不刷新、不绕过验证。参数、SKU 和卖家描述任一可用即可继续；超时仍保持缺失。

## 复验

本地自动化检查覆盖详情先于排序、每平台检查、详情复用、错商品及受限保护、型号冲突、拼多多紧邻参数与可见 ARIA 标签、闲鱼推荐字段污染、评论正文归属/否定表达和延迟渲染。

实站已定位拼多多罗技 M185 品牌/型号参数、京东三条鼠标评价，以及闲鱼主商品描述及卖家昵称。完整 MCP 和 Hermes 复跑返回见本轮证据附件。

## 仍需区分

页面可见品牌/型号是商家展示声明，不等于正品或厂商认证。可选颜色不等于已选 SKU，搜索价也未验证对应已选 SKU；`price_sku_verified=false`。闲鱼描述中提及的颜色、成色和售后不直接当作结构化实物证据。缺少已选配置、包装及成色时，仍不能确认真实同款跨商家最低价。
