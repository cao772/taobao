# 三平台详情与研究链路优化（2026-10-12）

继续现有 Issue #3 / Draft PR #2，main 不合并。本轮不请求仍受限的淘宝。

## 改动

- 拼多多：接入实站 `.iUUH2sOQ` 标签/值参数容器。视觉可见性依据 CSS 和布局判断，`aria-hidden` 不再被当作视觉隐藏；保留真正隐藏及透明内容检查。品牌和型号来自参数，不来自标题。
- 京东：读取 `.comment-root .list > .item > .info` 的实际评价正文，排除好评标签、累计人数及昵称。“没破损”这类否定表达不算破损风险。评价样本仍可能有偏，不核实真实购买，不生成质量分。
- 闲鱼：读取主商品描述和卖家显示名；“猜你喜欢”的品牌、成色标签不作为主商品参数。卖家自述保留为未核实声明，不用“全新”宣传直接填充成色。
- 参数排序：一次研究先对每个平台的符合目标及预算的候选读取详情，再分组和排序；默认每平台 1 条，可设为 0–2 条。之后读取短名单详情时复用本次缓存，避免重复导航。
- 详情冲突与回填：短名单读取后如型号或指定品牌不符，先排除再重新排序、回填下一候选；额外详情请求次数有上限。品牌不符仅表示不符合本次目标，不直接判断假货。
- 参数归属：详情商品 URL 必须与候选一致，受限或错商品的内容不会填进身份字段。标题含目标型号但详情显示不同型号时，按详情排除并保留证据。
- 客户端输出：默认精简研究报告移除重复搜索列表和重复参数；并发搜索报告仅保留一份完整商品列表，保留身份来源、评价正文/证据编号及明确的省略数量；`compact=false` 保留完整证据。避免 Hermes 工具结果超过输出上限而溢写，导致只用购物工具时无法继续读取。
- 二手边界：将实站参数中的“99成新/95成新”归为二手声明；未允许二手时排除，同时保留原参数来源，不据此保证实际成色。
- 目标过滤：补上鼠标电池盖、拆机配件等明确错项；如果用户明确搜索配件，不按整机目标排除。
- 渲染等待：导航后短暂等待详情 DOM，期间不刷新、不绕过验证。参数、SKU 和卖家描述任一可用即可继续；超时仍保持缺失。

## 复验

本地自动化检查覆盖详情先于排序、每平台检查、详情复用、错商品及受限保护、型号冲突、拼多多紧邻参数与可见 ARIA 标签、闲鱼推荐字段污染、评论正文归属/否定表达和延迟渲染。

本地 68 项测试通过。实站已定位拼多多罗技 M185 品牌/型号参数、京东三条鼠标评价，以及闲鱼主商品描述及卖家昵称。两端实际调用均完成：

| 客户端 | 请求平台 | 商品记录 | 研究内评价样本 | 清理 |
|---|---|---|---|---|
| Codex CLI（临时 gpt-5.5） | 京东、拼多多、闲鱼 | 18 | 3 | 释放外部会话引用 |
| Hermes（复用原模型） | 京东、拼多多、闲鱼 | 18 | 3 | 释放外部会话引用 |

Hermes 最终实测没有输出溢写或资源读取失败。两端都从自然语言调用平台发现、研究和清理工具；Hermes 额外读取了指定京东商品的 3 条评价，注明不用于其他商品。品牌冲突的商品被排除，第三条改为品牌参数符合本次罗技目标的候选；真实同 SKU 仍未确认。

证据：[Codex 工具返回](evidence/codex-optimization-2026-10-12.json)、[Hermes 工具返回](evidence/hermes-optimization-2026-10-12.json)。归档仅保留评论及卖家自述短摘录、来源、时间及正文哈希，完整结果在本机 `output/optimization-2026-10-12`。客户端实测后补上“99成新”归类，另用实站已取得的字段做 [回放验证](evidence/condition-replay-2026-10-12.json)：未允许二手时 0 条、允许二手时 1 条。本地最新 68 项测试覆盖此修复。

## 仍需区分

页面可见品牌/型号是商家展示声明，不等于正品或厂商认证。可选颜色不等于已选 SKU，搜索价也未验证对应已选 SKU；`price_sku_verified=false`。闲鱼描述中提及的颜色、成色和售后不直接当作结构化实物证据。缺少已选配置、包装及成色时，仍不能确认真实同款跨商家最低价。
